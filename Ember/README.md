# Ember Inochi2D Look Pack (for Claude)

What Ember looks like for Inochi2D: face, hair, jacket, body sprites/layers, and puppet `.inx` files.

## Layout
- `puppets_inx/` — live/project puppet files (`.inx`)
  - `ember_from_pc.inx` — from Nick’s PC (`C:\Users\nickf\ember.inx`, Sep 26 2026)
  - `ember_v068.inx` — larger extract (~24 MB)
  - `ember_body_first_pass_v7.inx` — latest body first-pass rig in archive
  - `ember_body_rig_v1.inx`
  - `ember_face_on_v2.inx` — face-on live copy
  - `ember_puppet_build.inx`
  - `ember_puppet_src.inx`
- `face_parts/` — head base, eyes, brows, ears, blinks, highlights
- `hair_layers/` — strand/cutout hair layers (front/back/side)
- `body_jacket_latest/` — `body/layers_v12` (arms, body, jacket, harness, hands, legs, hair_rear, physics)
- `jacket_history/` — jacket v5 + early head/jacket layer sets
- `masters_refs/` — master composite refs
- `ember_pc_sprites/` — expression sheets / face refs
- `docs/` — layer order / rules / manifest

Excluded: `.npy` work caches, deform stills, tool `_work` folders.
